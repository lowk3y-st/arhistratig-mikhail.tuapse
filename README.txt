САЙТ ХРАМА АРХАНГЕЛА МИХАИЛА В ТУАПСЕ
СБОРКА 1.8.4

КАК ОТКРЫТЬ
Откройте файл index.html двойным щелчком. Чтобы выложить сайт в интернет,
загрузите всю папку на хостинг целиком. Папки css, js и img должны лежать
рядом со страницами.

СТРАНИЦЫ
index.html     Главная: новости, о приходе, разделы
services.html  Расписание богослужений
treby.html     Требы и таинства
feasts.html    Праздники
school.html    Воскресная школа
youth.html     Молодёжное движение
photos.html    Фотографии
contacts.html  Контакты

КАК ДОБАВИТЬ НОВОСТЬ
1. Откройте index.html в любом текстовом редакторе (Блокнот подойдёт).
2. Найдите комментарий «НОВОСТИ» и блок <article class="frame news-item"> под ним.
3. Скопируйте блок целиком и вставьте перед ним: свежая новость идёт первой.
4. Замените дату, заголовок и текст. Фото положите в папку img и укажите
   его имя в двух местах блока (href и src).

КАК ОБНОВИТЬ РАСПИСАНИЕ
Расписание лежит в services.html. Оно записано дважды: таблица для планшетов
и компьютеров и карточки для телефонов. Правьте оба места. Проще всего
прислать новое расписание фотографией, и его перенесут в таблицу.


ДОПОЛНЕНИЕ
- Расписание само скрывает прошедшее по московскому времени. Служба исчезает через GRACE_HOURS (по умолчанию 2) часа после начала. Число меняется в начале блока про расписание в js/script.js.
- Данные расписания лежат в блоке <script id="sched-data"> в services.html (и копия в index.html для блока «Ближайшая служба»). Новое расписание проще всего прислать Claude, он пересоберёт сайт.
- Значок ВКонтакте: файл img/vk.png. Чтобы заменить, положите другой файл с тем же именем.
- Часы работы храма и лавки: блок class="hours" в index.html.

ФОТОГРАФИИ МОЛОДЁЖИ
Карусель на странице youth.html и сетка на photos.html собираются из файлов img/yp-01.webp ... yp-16.webp (полный размер) и yp-01-t.webp ... (уменьшенные для сетки). Телефон куратора и текст страницы молодёжи лежат в youth.html.

Праздничный баннер и красно-золотое оформление убраны (сборка 1.6.1), сайт бело-золотой.

ПРИЛОЖЕНИЕ (сборка 1.6.0)
Сайт работает как приложение (PWA): файлы manifest.webmanifest, sw.js и папка icons.
iPhone: открыть сайт в Safari, «Поделиться» -> «На экран Домой».
Android: в Chrome кнопка «Установить приложение» в меню сайта. Для APK-файла:
открыть pwabuilder.com, вставить адрес сайта, выбрать Android и скачать пакет.
Сайт должен быть на https. При изменении сайта поменяйте VERSION в sw.js.

АДМИНКА (сборка 1.8.3)
Вход: ссылка «Вход для администратора» внизу страницы контактов (admin.html).
Можно менять: новости (добавить, править, удалить), фото в альбомах, тексты страниц «Воскресная школа» и «Молодёжное движение».
Правки сохраняются в репозиторий (папка data/ и img/uploads/), GitHub Pages публикует их за 1-2 минуты.
Первая настройка: открыть admin-setup.html, создать admin-config.json и загрузить его в корень репозитория.
При обновлении сайта новым архивом папки data/, img/uploads/ и файл admin-config.json не трогайте и не удаляйте.
Пароль нигде не хранится, он только расшифровывает ключ доступа в admin-config.json. Сменить пароль: снова создать admin-config.json на admin-setup.html.
При входе админка проверяет репозиторий, ветку и права ключа. Если что-то не так, над вкладками появляется красная строка с причиной. Текст ошибки 404 при сохранении теперь содержит ответ GitHub.
Страница admin-setup.html проверяет токен на GitHub до создания файла и не принимает значение, не похожее на токен (его могло подставить окно сохранённых паролей браузера).
При ошибке 401 админка пишет, какой ключ она загрузила из admin-config.json (длина, формат, дата создания файла). Новый файл настроек получает дату создания.
Главное фото храма (img/church.webp) заменено на вырезанное без фона, размер 1086x1448. Чтобы заменить снова, положите файл с тем же именем и поменяйте число в src после ?v= в index.html.
