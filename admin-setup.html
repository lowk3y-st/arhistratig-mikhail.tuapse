Эта страница создаёт файл admin-config.json. В нём ключ доступа к вашему репозиторию GitHub хранится в зашифрованном виде: расшифровать его можно только логином и паролем. Всё считается в вашем браузере, ничего никуда не отправляется. Пароль в файле не хранится.

  1. На GitHub откройте Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. В «Repository access» выберите Only select repositories и отметьте репозиторий сайта. В «Permissions → Repository permissions» поставьте Contents: Read and write. Срок действия поставьте максимальный.
  3. Скопируйте токен (он показывается один раз) и вставьте ниже вместе с логином и паролем.
  4. Нажмите «Создать файл», скачайте admin-config.json и загрузите его в корень репозитория рядом с index.html. После этого эту страницу (admin-setup.html) можно удалить.
